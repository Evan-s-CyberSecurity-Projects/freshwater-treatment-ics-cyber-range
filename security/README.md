# Security

This directory documents the cybersecurity architecture, attack surface,
detection strategy, and controlled incident scenarios for the Freshwater
Treatment ICS Cyber Range.

The security model is designed around an isolated educational environment
where industrial systems can be studied from both the attacker and defender
perspectives.

The primary goal is to understand how a cyber event can move through an
industrial environment and how security teams can detect, investigate, and
respond to that activity.
